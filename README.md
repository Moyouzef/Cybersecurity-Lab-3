## Lab Documentation
Step 1 — Setting Up John the Ripper

The first step of my lab was to set up John the Ripper (JTR) in Kali Linux.

I started by accessing the John the Ripper Jumbo project on GitHub and copied the appropriate repository link. I then used the link in my Kali Linux terminal to download and set up John the Ripper.

After completing the setup, I verified that John the Ripper was available and ready to use in my Kali Linux environment.

Step 2 — Preparing the PDF for Password Testing

Once John the Ripper was installed, I worked with the password-protected PDF provided for the lab.

Before John the Ripper could test the password, I first needed to extract the password hash information from the PDF. The hash contains the information that John the Ripper uses during the password-auditing process.

I then prepared the extracted hash so that it could be used with John the Ripper.

Step 3 — Testing the Password

After preparing the hash, I used John the Ripper to perform the password-cracking exercise against the PDF hash.

John the Ripper tested possible passwords against the hash until it identified the correct password.

The exercise successfully revealed the password for the PDF.

Step 4 — Result

After completing the process, I was able to recover the password successfully.

This practical exercise helped me understand the relationship between:

Password-protected PDF → Password Hash → John the Ripper → Password Recovery
